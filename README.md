# Study Cafe DBMS

A Study Cafe Reservation and Management System developed using Node.js, Express.js, and MySQL.

## Technologies Used

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Create a .env file using .env.example as a guide.
4. Configure your MySQL database.
5. Start the server:

   npm run dev

6. Open http://localhost:3000 in your browser.

## Project Structure

- backend/ - Backend files
- backend/config/ - Database configuration
- backend/controllers/ - Controller files
- backend/models/ - Database models
- backend/public/ - Frontend assets
- backend/routes/ - Application routes
- backend/sql/ - Database scripts
- index.js - Main server file
